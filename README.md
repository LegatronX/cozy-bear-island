# 🐻 Cozy Bear Island

Petit jeu d'aventure **cozy** entièrement en HTML + Canvas (aucun framework, aucune dépendance).

Tu incarnes un ours sur une île paisible. Secoue des arbres, pêche, parle aux villageois, cueille des fleurs, vends tes trouvailles à Pépé, et surveille la météo qui change vraiment.

## Jouer tout de suite

Ouvre simplement le fichier `index.html` dans ton navigateur.

**Contrôles**
- Clavier : `WASD` / flèches pour bouger · `E` pour interagir · `F` pour manger un fruit
- Mobile : pad directionnel + bouton E + bouton 🍎
- Glisser n'importe où sur l'écran pour marcher

## Fonctionnalités

- **Météo dynamique** : beau temps, nuageux, pluie, orage (vent, feuilles, éclairs, bonus sous la pluie)
- Système d'**énergie** (manger des fruits ou se reposer dans ta cabane)
- Marchand (Pépé) qui rachète ton inventaire
- Missions quotidiennes qui se relancent au lever du soleil
- Sauvegarde automatique (localStorage)
- Dialogues variés
- Cycle jour / nuit + lucioles
